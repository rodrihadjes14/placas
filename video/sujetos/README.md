# Imágenes del sujeto para las tapas de los Reels informativos

Desde el 16/11/2026 la tapa de los Reels informativos (grabados) usa de fondo una de estas imágenes: el abogado solo,
sin placas ni subtítulos, a 1080x1920 y con el mismo encuadre que el video (de la cadera para arriba). `tapa.py` le
pone encima la etiqueta y el gancho de cada Reel. Los Reels de caso real siguen usando un cuadro de su propio gancho.

Si hay más de una imagen, rotan según el número del ID de la fila (T130 → imagen 130 % cantidad).

- `sujeto-01.jpg`: cuadro limpio de la grabación AD-03 (segundo 11,32), el mismo de la tapa de referencia que eligió el estudio.
